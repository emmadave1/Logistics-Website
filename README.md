# Logistics Website

A modern logistics and shipment management web application built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**. The application provides a clean, responsive interface for managing shipments, tracking delivery requests, and improving customer experience.

## Features

- Shipment tracking
- Logistics request management
- Admin dashboard
- Responsive design
- Modern and intuitive UI
- Fast performance with Vite
- Built with Tailwind CSS
- Scalable project structure

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Router
- React Hook Form
- Radix UI
- Lucide React

## Getting Started

### Clone the repository

```bash
git clone https://github.com/emmadave1/logistics-website.git
```

### Navigate into the project

```bash
cd logistics-website
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at:

<http://localhost:5173>

## Build for Production

```bash
npm run build
```
